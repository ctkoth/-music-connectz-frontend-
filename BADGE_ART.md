# BadgeZ art — the file names to draw

Save each one as a **.jpg** with exactly this name, drop it into `public/icons/`, run
`node tools/build-icon-manifest.mjs`, and it replaces that badge's neon placeholder.
Nothing else changes. Square works best (512×512 or bigger); the medal is shown round.
