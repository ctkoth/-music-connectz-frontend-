# Play custom store listings (Music ConnectZ)

Three custom listings × 50 languages + en-US (153 files). Each file has `SHORT:` (≤80) and `FULL:` (≤4000). A script checked the limits.

| Folder | Leads with | Short description | Use it for |
|---|---|---|---|
| `coach/` | 🎙️ Record a take, get it scored | AI coach: score, fixes, a drill | musicians who want feedback (ads/URL aimed at singers, rappers, instrumentalists) |
| `collab/` | 🤝 Collab without getting burned | escrow-backed pay, one post, everyone credited | producers, cover artists, videographers |
| `earn/` | ⭐ Get rated on what you did | rated on real work, rate from your record | working artists who care about pay |

- **What differs from the default listing:** the short description is new, and the full description is the same text with the chosen section moved to the top. Everything else (every claim, every product name) is unchanged, so no custom listing promises something the default doesn't.
- **Title:** Play keeps the app title on custom listings, so there is no title file. Titles stay in `../translations/`.
- **Targeting is set in Play Console**, not in these files (countries, users who haven't installed / lapsed users, pre-registration, or a URL for ads). Pick the audience for each listing there.
- Graphics (screenshots, feature graphic) are separate per custom listing in the console; reuse `store/screenshots/`.
- Emoji and Z plurals follow the default listing. Machine translation, not reviewed by a native speaker.
